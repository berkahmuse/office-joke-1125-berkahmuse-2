## The joke

> I wear noise-cancelling headphones to look busy, so now even my own thoughts need a calendar invite.

100 characters, one line. The office detail is specific (headphones
as a do-not-disturb shield, the calendar invite); the last words turn
the shield back on its wearer — it works so well that even his own
thoughts must book a meeting. A familiar setup taken somewhere
unexpected. Reads cleanly in one pass, nothing left to cut.

## How it works

`main.py` writes the joke to `/output/entry.txt` (no trailing newline,
so the file holds exactly the 100 characters of the joke). Run it
locally with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/joke-out python3 main.py
```
